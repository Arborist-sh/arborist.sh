One image. Your Mac and your CI.

Graft bakes one golden macOS VM from a .graft recipe, then uses that same image as your dev box and as your GitHub Actions runners.

Same image on both branches. Caches are baked in, so “works on my machine” stops being a category.

How it works

Write the seed once. Grow it once. Use it everywhere.

01 · seed

A declarative .graft file is YAML with declarative toolchain fields: a base image, toolchain versions, the things to bake in.

name: ios-fastlane
from: ghcr.io/cirruslabs/macos-tahoe-xcode
ruby: "3.3.5"
gems: [fastlane]

02 · nest

graft nest clones the image into a dev box. Shell in, or open it in VS Code over Remote-SSH. Codespaces, for native macOS and iOS.

$ graft nest

03 · tend

graft arborist tend boots a fresh clone per GitHub Actions job as a JIT runner, runs exactly one job, then destroys it.

$ graft arborist tend

A hosted fleet control plane is on the roadmap.

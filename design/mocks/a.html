One image. Your Mac and your CI.

Graft bakes one golden macOS VM from a recipe, then uses that same image two ways: a dev box you shell into, and ephemeral GitHub Actions runners. Works on my machine stops being a thing. Open source, MIT, Apple Silicon.

$ brew install cirruslabs/cli/tart && brew install arborist-sh/tap/graft

Prefer a window? brew install --cask arborist-sh/tap/graft-app

How it grows

Bake the sapling once. Use it everywhere.

graft sapling grow

Builds the golden Tart image from a declarative .graft recipe, the seed. Xcode DerivedData, CocoaPods, node_modules and ccache are baked in once.

graft nest

A dev box cloned from the sapling: shell in, or open it in VS Code over Remote-SSH. Codespaces for native macOS and iOS.

graft arborist tend

Each runner boots fresh, registers as a JIT runner, runs exactly one job, and is destroyed. APFS copy-on-write clones make the baked caches free per runner.

A hosted fleet control plane is on the roadmap. For now, multi-host fleets run through Orchard.
